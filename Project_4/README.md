# ChocAn Project 4

ChocAn supports provider billing and directory access, operator maintenance of member and provider records, and manager reports and weekly accounting. The Swing interface and the terminal use the same Java controllers and database. The optional `--state` setting saves records between sessions.

- [Build, run, and demonstrate the program](docs/RUN.md)
- [Core UML](uml/PNG/ChocAn_Project4_Core_Class_Diagram.png) and [Swing UML](uml/PNG/ChocAn_Project4_Swing_Class_Diagram.png). Cards marked (reference) in the Swing view refer to the corresponding Core classes. Editable versions are in [uml/UXF](uml/UXF).
