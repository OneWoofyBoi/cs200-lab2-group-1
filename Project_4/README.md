# ChocAn Project 4

ChocAn supports provider billing and directory access, operator maintenance of member and provider records, and manager reports and weekly accounting. The Swing application saves records when the window closes and loads them the next time it opens in the same project folder.

- [Build and run the program](docs/RUN.md)
